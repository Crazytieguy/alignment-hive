# debrief

Delegating well means a short stretch in the loop at the start and at the end, and a long one out of it in between, so you can run several tasks in parallel. The end is where you review, and reviewing every single thing the agent did is no longer viable if you want to scale up the work you produce. `/debrief:debrief` turns a finished session into the review you need: what was done and why, the decisions with the highest risk of not being what you meant, the side effects, and how the work was verified, on one page. For fuzzy tasks without a solid test or metric, it's how you get quality without reading everything. Comment on it and ask for another round; the next round answers your comments and marks what's new since you last looked.

A fork of the session writes the page with the hive CLI (0.2.0 or later), and the session publishes it as a private claude.ai artifact. Requires `hive@alignment-hive`, and `jq` for the SessionStart hook. The page loads four pinned scripts from cdnjs/jsDelivr and its fonts from Google Fonts. Debriefs live in the plugin's data directory, and each round has an immutable manifest; seen marks are kept in the artifact's database.
