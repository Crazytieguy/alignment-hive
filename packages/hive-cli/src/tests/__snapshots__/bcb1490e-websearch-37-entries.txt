  No current WorkOS outages. The last incident was March 17 (elevated API errors, resolved within ~90 minutes). Service has been stable since.

  For slow magic link emails specifically, the most common causes are:

  - **Enhanced Pre-delivery Message Scanning** on Google Workspace (or similar features on other providers) — this adds delay before the email appears in the inbox
  - **Email provider spam filtering** — the magic link email might be landing in spam/junk
  - **Domain reputation** — if it's slow for everyone, could be a reputation issue with the sending domain

  WorkOS also notes that **Magic Link is deprecated in favor of Magic Auth** (which uses a code instead of a link), partly because email clients/security software can pre-visit links and invalidate them.

  Could be worth asking affected users to check their spam folder, and whether they're on Google Workspace with scanning enabled.

  Sources:
  - [WorkOS Status](https://status.workos.com/)
  - [WorkOS Email Delivery Docs](https://workos.com/docs/email)
  - [WorkOS Magic Auth Docs](https://workos.com/docs/authkit/magic-auth)

  Custom email domains on WorkOS cost **$99/month** on top of any plan — they're not included in the free tier.

  On the DNS side it would work fine with Vercel (just add 3 CNAME records + a DMARC TXT record), but the price is probably not worth it for this.

  Realistically your best options are probably:
  - Add a note in the sign-in flow telling users to check spam/wait a minute
  - If it's consistently slow, reach out to WorkOS support — they monitor email delivery and might be able to help
