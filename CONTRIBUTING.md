## Contributing

### Branch Naming

Please create branches with:
`<your-github-slug>/<change-type>/<short-description>`
Where:

- <your-github-slug> is your GitHub username, or a unique identifier
- <change-type> is one of "bug", "feature", "refactor", or "docs"
- <short-description> is a short description of the change, e.g. "fix-typo-in-readme"

Example: `alice/bug/fix-typo-in-readme`

### Pull Requests

Pull Request Titles should be in the format:
`Change-Type: <Short description of the change> (#<issue-number>)`

Where:

- Change-Type is one of "Bug", "Feature", "Refactor", or "Docs"
- Short description is a concise summary of the change, e.g. "Fix typo in README"
- #issue-number is the number of the GitHub issue that this PR addresses. If there isn't an issue, please create one and link to it in the PR description.
